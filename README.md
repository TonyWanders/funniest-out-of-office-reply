A program that writes one funny one-line out-of-office reply to
`/output/entry.txt`, for the make.fun competition
[Funniest One-Line Out-of-Office Reply](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8).

Run it with Python 3:

```
python3 main.py
```

It writes the reply below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The reply is 63 characters, inside the 1 to 160 gate.

## The reply

```
I am away from my desk, my inbox, and my will to answer either.
```
